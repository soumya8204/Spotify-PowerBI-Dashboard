# Spotify Songs Analysis Power BI Dashboard

## Project Overview
This project presents an interactive dashboard built using Microsoft Power BI to analyze Spotify song data from 2015–2025. The dashboard analyzes 18,000+ songs to identify music trends, artist performance, and genre distribution using data visualization techniques.

## Objectives
- Analyze Spotify music data to identify listening trends
- Study artist and genre performance over time
- Perform data cleaning and transformation
- Create interactive visualizations for data exploration

## Dataset
The project uses a Spotify dataset containing 18,000+ songs collected over a 10-year period (2015–2025).

## Tools Used
- Microsoft Power BI
- Power Query
- Data Cleaning and Transformation
- Data Visualization
- Dashboard Design

## Features
- Interactive dashboard with filters and slicers
- Analysis of song popularity and trends
- Genre and artist performance insights
- KPI metrics for data analysis
- Dynamic visualizations

## Project Workflow
1. Data collection and loading
2. Data cleaning using Power Query
3. Data transformation and modeling
4. Dashboard development
5. Data visualization and trend analysis
